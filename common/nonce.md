# nonce

## nonce?

- nonce (Number used once)
    - 단 한 번만 사용되는 값
- 사용처에 따라 유사한 역할을 하는 값의 명칭이 nonce, IV(initialize vector) 로 사용될 수 있음
    - 동일 키로 동일 평문 암호화시 결과값이 달라지게 하기 위함 목적
- nonce 값은 유일성(비반복)이 보장 필수
    - 반드시 무작위 난수 값일 필요는 없음 카운터, 타임스탬프 등도 사용될 수 있음
- 재전송 공격 방지와 대칭키 암호화 시 사용
- 평문 암호화시 nonce 값을 포함해서 암호화하여 동일 키로 동일 평문 암호화시 결과값을 매번 다르게 하고, nonce 값은 암호문과 같이 저장하거나 공개하여 복호화시 사용
- 동일 키로 암호화시 암호화 대상 평문과 무관하게 nonce 값은 항상 달라져야 한다.
    - 암호화시 키 + nonce 로 키스트림을 생성하고 키스트림을 평문에 섞어서 암호문을 생성함
    - 이 키스트림은 평문과 무관하게 키 + nonce 로만 만들어지는 것.
    - 때문에 nonce가 같으면 평문이 달라도 똑같은 키스트림이 섞임. 즉, 같은 키스트림이 섞인 암호문 두 개를 공격자가 얻으면 서로 비교해서 그 키스림을 지워버릴 수 있음
    - 키스트림이 지워지만 키 업싱도 평문에 대한 정보가 드러남

## nonce 용도

- 재전송 공격 방지
    - 수신한 데이터가 재전송된 것이 아님을 보장
    - 매 요청마다 비반복되는 nonce 값을 포함
    - HTTP Digest, OIDC nonce, TLS ClientHello ...
- 대칭키 암호화시 동일 키 동일 평문 암호화시 결과 달리하기 위한 목적

## 대칭키 암호화에서 nonce 가 필요한 이유

- 같은 키로 같은 평문을 암호화 시 항상 같은 암호문이 나오면(=결정적 암호화), 공격자는 내용을 몰라도 같은 메세지가 다시 전송되었다는 사실을 알 수 있음
    - 반복되는 패턴 또한 관찰 가능
- 키는 그대로 두고 암호화 시마다 달라지는 nonce 값을 함께 넣어서 같은 평문이라도 매번 다른 암호문이 나오도록 한다.
- 복호화시 암호화에 사용된 nonce 값은 정확히 알아야 복호화 가능
